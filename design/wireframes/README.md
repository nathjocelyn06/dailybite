# Wireframes (v3 · narrowed DailyBite, Chroma palette)

Each `.dc.html` is one screen from the DailyBite design canvas (open it in a browser; the
markup between `<x-dc>` tags is the layout, and the `<script data-dc-script>` block holds
the interaction logic, e.g. drag-to-decorate in `D06-Fridge.dc.html`).

| Tab | Desktop | Phone |
|---|---|---|
| **Home** (pastel hero + today card, service grid + More sheet, yellow tip) | D01 Home · D08 My progress (AI overview) · D07 Budget · D11 Notifications | M01 Home (More opens the all-services sheet) |
| **My Kitchen** (Fridge + Recipes only) | D00 My Kitchen · D06 Fridge (Stock · To buy) · D03 Recipes (Find · Saved · Cook from fridge) · D04 Recipe detail | M07 My Kitchen · M05 Fridge |
| **Journal** | D05 Food journal editor | M04 Journal |
| **Archive** (List / Calendar switch) | D09 Archive list · D02 Calendar | M08 Archive · M06 Calendar |
| Global | D12 AI camera · D13 Daily date change & sync | M02 Camera sheet · M03 Confirm scan |
| Reference | Sketches · Sitemap (v3 IA) · Main (earlier scaffold) | |

Desktop sidebar: Home, My Kitchen, Journal, Archive, then Account (Notifications, Settings).
Below 760 px each desktop wireframe turns its sidebar into the same 4-tab bottom bar.
Colours: see the "Look (v3)" section of docs/PLAN.md.
